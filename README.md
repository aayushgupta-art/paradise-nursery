# Paradise Nursery Shopping Application

An interactive e-commerce web application built with React and Redux Toolkit for an online plant shop called **Paradise Nursery**. 

## Features
* **Landing Page:** Features a welcoming interface with company details and a "Get Started" button.
* **Product Catalog:** Organizes unique houseplants into distinct categories with images, names, and prices.
* **Shopping Cart Management:** Allows users to add plants to the cart, dynamically increment/decrement quantities, remove items, and see calculated totals.
* **Navigation Bar:** Persistent navbar across pages showing links to Home, Plants, and a dynamic Cart item counter.

## Tech Stack
* React.js
* Redux Toolkit
* CSS3 / Modern JavaScript
